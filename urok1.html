Слайд 6

Формула вероятности события

\(P(A) = \dfrac{m}{n}\)

\(n\) — общее число равновозможных элементарных событий опыта;

\(m\) — число благоприятствующих событию \(A\) исходов.

Смысл: вероятность — это доля благоприятствующих исходов среди всех возможных. Как если бы мы «вырезали» нужные кусочки из целого.
Сравнение с прошлым уроком

Если событие элементарное, то \(m = 1\), и формула даёт \(P = \dfrac{1}{n}\) — то, что мы уже знаем.

Пример 1: «выпало чётное число»

Задача

Бросают правильный кубик. Найдите вероятность события \(A\) = «выпало чётное число».

  1. Всего исходов: \(n = 6\).
  2. Благоприятствующие: 2, 4, 6 → \(m = 3\).
  3. По формуле: \(P(A) = \dfrac{m}{n} = \dfrac{3}{6} = \dfrac{1}{2}\).

\(P = \dfrac{1}{2} = 0{,}5\).

Слайд 12

Свойства вероятности

Из формулы \(P(A) = \dfrac{m}{n}\) следуют важные свойства.

Главное свойство

Вероятность любого события заключена между \(0\) и \(1\):

\(0 \leq P(A) \leq 1\)

\(P = 0\)

Невозможное событие.

Благоприятствующих исходов нет: \(m = 0\).

\(0 < P < 1\)

Случайное событие.

Часть исходов благоприятствует, часть — нет.

\(P = 1\)

Достоверное событие.

Благоприятствуют все исходы: \(m = n\).

Связь с прошлым уроком: достоверное → \(1\), невозможное → \(0\), случайное → между \(0\) и \(1\). Формула \(P = \dfrac{m}{n}\) это подтверждает.

Слайд 15

Противоположное событие

Определение

Событие \(\overline{A}\) (читается «не \(A\)») называют противоположным событию \(A\). Оно наступает тогда и только тогда, когда не наступает \(A\).

Пример: кубик

\(A\) = «выпало чётное число» → \(A\): 2, 4, 6.

\(\overline{A}\) = «выпало нечётное число» → \(\overline{A}\): 1, 3, 5.

1
2
3
4
5
6

Зелёные — благоприятствуют \(\overline{A}\).

Важно: события \(A\) и \(\overline{A}\) вместе покрывают все исходы опыта, и при этом не пересекаются.
Слайд 16

Вероятность противоположного события

\(P(\overline{A}) = 1 - P(A)\)

Сумма вероятностей противоположных событий равна \(1\):

\(P(A) + P(\overline{A}) = 1\)

Почему? Благоприятствующие исходы \(A\) и \(\overline{A}\) вместе составляют все \(n\) исходов. Значит, \(m + m' = n\), откуда \(\dfrac{m}{n} + \dfrac{m'}{n} = 1\).
Пример

Вероятность попасть в цель \(P(A) = 0{,}7\). Какова вероятность промахнуться?

Показать ответ

\(P(\overline{A}) = 1 - 0{,}7 = 0{,}3\).

Задача из учебника: кубик

Задача

Бросают правильный игральный кубик. Найдите вероятности событий:

  • \(A\) — выпало 3 очка;
  • \(B\) — выпало не менее 4 очков;
  • \(C\) — выпало число, кратное 2;
  • \(D\) — выпало число, большее 7.
Показать ответы

\(n = 6\) во всех случаях.

\(A\): \(m = 1\) → \(P = \dfrac{1}{6}\).

\(B\): исходы 4, 5, 6 → \(m = 3\) → \(P = \dfrac{3}{6} = \dfrac{1}{2}\).

\(C\): исходы 2, 4, 6 → \(m = 3\) → \(P = \dfrac{3}{6} = \dfrac{1}{2}\).

\(D\): таких исходов нет → \(m = 0\) → \(P = 0\) (невозможное событие).

Слайд 20

Типичные ошибки

Ошибка 1

Считать \(n\) «по событию», а не по опыту.

Неверно: для события «выпало чётное» брать \(n = 3\).

Верно: \(n = 6\) — это все исходы опыта, а \(m = 3\).

Ошибка 2

Забывать сокращать дробь или путать \(m\) и \(n\).

Неверно: \(P = \dfrac{6}{3}\).

Верно: \(P = \dfrac{m}{n}\), и ответ лучше давать несократимой дробью.

Ошибка 3

Применять формулу \(\dfrac{m}{n}\), когда исходы не равновозможны.

Например, для утяжелённого кубика или мешка с разным числом шаров эта формула не работает.

Проверка: перед применением формулы убедитесь, что все элементарные события равновозможны.
Слайд 21

Задача: карточки 1–10

Задача

В коробке карточки с числами от 1 до 10. Наугад вытягивают одну карточку. Найдите вероятности событий:

  • \(A\) — вытянули число 7;
  • \(B\) — вытянули чётное число;
  • \(C\) — вытянули число, кратное 5;
  • \(D\) — вытянули число, большее 10.
Показать ответы

\(n = 10\).

\(A\): \(m = 1\) → \(P = \dfrac{1}{10}\).

\(B\): 2, 4, 6, 8, 10 → \(m = 5\) → \(P = \dfrac{5}{10} = \dfrac{1}{2}\).

\(C\): 5, 10 → \(m = 2\) → \(P = \dfrac{2}{10} = \dfrac{1}{5}\).

\(D\): \(m = 0\) → \(P = 0\) (невозможное событие).

Слайд 22

Задача: шары в мешке

Задача

В мешке 5 красных, 3 синих и 2 зелёных шара. Все шары одинаковы на ощупь. Наугад вытягивают один шар.

  1. Сколько всего элементарных исходов?
  2. Найдите вероятность вытянуть красный шар.
  3. Найдите вероятность вытянуть не синий шар.
Показать ответы

1. \(n = 5 + 3 + 2 = 10\).

2. Красных 5 → \(P = \dfrac{5}{10} = \dfrac{1}{2}\).

3. Не синих \(10 - 3 = 7\) → \(P = \dfrac{7}{10}\).

Или через противоположное: \(P(\text{синий}) = \dfrac{3}{10}\), значит \(P(\text{не синий}) = 1 - \dfrac{3}{10} = \dfrac{7}{10}\). ✅

Обрати внимание: здесь исходы равновозможны только потому, что шары одинаковы на ощупь. Если бы шары отличались по размеру — формула не подошла бы.

Слайд 24

Схема решения задачи на вероятность

1. Понять, что такое элементарное событие опыта
↓
2. Посчитать \(n\) — число всех равновозможных исходов
↓
3. Перечислить благоприятствующие исходы, найти \(m\)
↓
4. Применить формулу \(P = \dfrac{m}{n}\)
↓
5. Сократить дробь и проверить \(0 \le P \le 1\)
Совет: если задача про «хотя бы один» — часто проще найти вероятность противоположного события и вычесть из \(1\).
Слайд 25

Задача: игральные карты

Задача

Из колоды в 36 карт наугад вытягивают одну карту. Найдите вероятности событий:

  • \(A\) — вытянули туза;
  • \(B\) — вытянули карту пиковой масти;
  • \(C\) — вытянули красную карту;
  • \(D\) — вытянули не туза.
Показать ответы

\(n = 36\).

\(A\): тузов 4 → \(P = \dfrac{4}{36} = \dfrac{1}{9}\).

\(B\): пик 9 → \(P = \dfrac{9}{36} = \dfrac{1}{4}\).

\(C\): красных (черви + бубны) 18 → \(P = \dfrac{18}{36} = \dfrac{1}{2}\).

\(D\): \(P(\text{туз}) = \dfrac{1}{9}\), значит \(P(\text{не туз}) = 1 - \dfrac{1}{9} = \dfrac{8}{9}\).

Слайд 27

Задание: выбери верную формулу

Как найти вероятность события \(A\), если все исходы равновозможны?

\(P(A) = \dfrac{n}{m}\)
\(P(A) = \dfrac{m}{n}\)
\(P(A) = m \cdot n\)
\(P(A) = m - n\)
Проверка

\(m\) — благоприятствующие, \(n\) — все исходы. Благоприятствующих не может быть больше, чем всех, поэтому \(m \le n\) и \(P \le 1\).
